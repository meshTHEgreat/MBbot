The experimental strategy الاستراتيجية التجريبية

From dataset to verified receipt من مجموعة البيانات إلى إيصال تحقق موثّق

Each stage must pass in chronological order. A missing bar, stale underlying point, invalid quote, or failed filter means no entry.

يجب اجتياز كل مرحلة وفق ترتيبها الزمني. ويؤدي غياب شمعة، أو تقادم سعر الأصل، أو عدم صلاحية التسعير، أو فشل أحد المرشحات إلى عدم الدخول.

  1. 01

    Choose an available dataset and universe

    اختيار مجموعة بيانات متاحة ونطاق الرموز

    The selected local profile defines its dates and supported symbols. The browser cannot alter a filesystem path or request additional dates.

    يحدد الملف المحلي المختار التواريخ والرموز المتاحة، ولا يمكن للمتصفح تعديل مسار الملفات أو طلب تواريخ إضافية.

  2. 02

    Find the nearest eligible call and put

    تحديد أقرب عقد شراء وعقد بيع مؤهلين

    The replay starts with the nearest permitted expiration. Calls use the nearest strike at or below spot; puts use the nearest strike at or above spot. Price and spread caps are strict “less-than” filters.

    تبدأ المحاكاة بأقرب تاريخ انتهاء مسموح. ويُختار لعقد الشراء أقرب سعر تنفيذ يساوي سعر الأصل أو يقل عنه، ولعقد البيع أقرب سعر تنفيذ يساويه أو يزيد عليه. ويُطبَّق حدّا السعر والفارق بصيغة «أقل من» بصورة صارمة.

  3. 03

    Wait for a bullish MACD crossover

    انتظار تقاطع إيجابي لمؤشر MACD

    On the selected option contract’s own completed five-minute chart, the previous MACD must be at or below its signal line and the current MACD must be above it. A bearish crossover is not an entry in this experimental test.

    على الرسم الخاص بعقد الخيار نفسه ولفاصل خمس دقائق مكتمل، يجب أن تكون قيمة MACD السابقة مساوية لخط الإشارة أو أدنى منه، ثم تصبح القيمة الحالية أعلى من خط الإشارة. ولا يُعد التقاطع السلبي إشارة دخول في هذا الاختبار التجريبي.

  4. 04

    Enter at the first qualifying ask

    الدخول بأول سعر طلب مؤهل

    The quote must occur at or after the completed signal bar and no more than 15 seconds later. If call and put both signal on the same bar, both entries are rejected.

    يجب أن يَرِد التسعير عند اكتمال شمعة الإشارة أو بعده، وبفاصل لا يتجاوز 15 ثانية. وإذا ظهرت إشارة متزامنة لعقد الشراء وعقد البيع على الشمعة نفسها، تُرفض الإشارتان معاً.

  5. 05

    Exit on the first observed condition

    الخروج عند أول شرط متحقق زمنياً

    A later executable bid closes the position when the profit target, an opposite completed-bar MACD crossover, or the configured Riyadh-time exit occurs first.

    يُغلق المركز بأول سعر عرض قابل للتنفيذ بعد تحقق أول شرط زمنياً: هدف الربح، أو تقاطع MACD عكسي على شمعة مكتملة، أو موعد الخروج المحدد بتوقيت الرياض.

  6. 06

    Replay again and verify every receipt field

    إعادة المحاكاة والتحقق من جميع حقول الإيصال

    MBbot repeats the deterministic replay and compares timestamps, fills, indicators, source rows, and fingerprints before a report can be published.

    يعيد MBbot تشغيل المحاكاة الحتمية ويقارن التوقيتات وأسعار التنفيذ والمؤشرات وصفوف المصدر والبصمات الرقمية قبل السماح بنشر التقرير.

Do not merge this backtest with the live signal logic. لا تخلط منطق هذا الاختبار بمنطق الإشارات الحية.

The live bot currently reads the underlying’s completed five-minute chart and maps bullish to calls and bearish to puts. This isolated backtest instead monitors eligible option contracts independently and requires a bullish crossover on the contract being entered.

يعتمد البوت الحي حالياً على الرسم المكتمل للأصل الأساسي لفاصل خمس دقائق، فيربط التقاطع الإيجابي بعقد شراء والتقاطع السلبي بعقد بيع. أما هذا الاختبار المعزول فيراقب عقود الخيارات المؤهلة بصورة مستقلة، ويشترط تقاطعاً إيجابياً على العقد المراد الدخول فيه.

MACD periods and EMA seed

فترات MACD وطريقة تهيئة المتوسط الأسي

Fast, slow, and signal periods determine how many completed contract closes feed each line. Shorter periods generally react sooner; longer periods generally smooth more. The page requires the fast period to remain below the slow period.

تحدد الفترات السريعة والبطيئة وفترة الإشارة عدد إغلاقات العقد المكتملة الداخلة في احتساب كل خط. وتكون الفترات الأقصر عادة أسرع استجابة، بينما توفر الفترات الأطول تنعيماً أكبر. وتشترط الصفحة بقاء الفترة السريعة أقل من الفترة البطيئة.

Optional · disabled baseline

Zero-line and RSI filters

مرشح خط الصفر ومرشح RSI

The zero-line filter accepts the bullish cross only when current MACD is above zero. RSI uses Wilder’s calculation on the same contract closes and accepts only values inside the configured range. RSI is built but disabled in the baseline.

يقبل مرشح خط الصفر التقاطع الإيجابي فقط عندما تكون قيمة MACD الحالية أعلى من الصفر. ويستخدم RSI طريقة وايلدر على إغلاقات العقد نفسه، ولا يقبل إلا القيم الواقعة ضمن النطاق المحدد. وقد بُني RSI تقنياً لكنه معطل في الإعداد الأساسي.

Research questionسؤال بحثي Does the filter remove weak signals, or merely reduce the sample until the result becomes unstable? هل يستبعد المرشح الإشارات الضعيفة فعلاً، أم يخفض حجم العينة حتى تصبح النتيجة غير مستقرة؟

Premium, spread, expiration, and strike fallback

سعر العقد والفارق والانتهاء والانتقال بين أسعار التنفيذ

The premium cap uses the executable ask. The spread cap can use either midpoint or ask as its denominator. Disabling a cap changes eligibility; it does not create a missing quote. The fallback switches decide whether the scan may continue beyond the nearest strike or expiration.

يعتمد حد سعر العقد على سعر الطلب القابل للتنفيذ. ويمكن حساب نسبة الفارق باستخدام السعر المتوسط أو سعر الطلب مقاماً للنسبة. ويؤدي تعطيل الحد إلى تغيير أهلية العقد، لكنه لا يعالج غياب التسعير. وتحدد مفاتيح الانتقال ما إذا كان البحث يستمر بعد أقرب سعر تنفيذ أو تاريخ انتهاء.

America/New_York session · Asia/Riyadh exit

Entry window and forced time exit

نافذة الدخول وموعد الخروج الإلزامي

The default waits 15 minutes after the recorded US option-session open and stops new entries 60 minutes before its recorded close. The forced exit is an explicit Asia/Riyadh clock time. Exchange holidays and shortened sessions come from the saved session file.

ينتظر الإعداد الافتراضي 15 دقيقة بعد افتتاح جلسة الخيارات الأمريكية المسجلة، ويوقف الدخول الجديد قبل إغلاقها المسجل بساعة. أما الخروج الإلزامي فيُحدد صراحة وفق توقيت Asia/Riyadh. وتُستمد العطلات والجلسات المختصرة من ملف الجلسات المحفوظ.

First chronological condition wins

Profit, opposite MACD, and timed exits

الخروج بالربح أو التقاطع العكسي أو الوقت

Profit is measured from entry ask to a later executable bid. The opposite-MACD exit uses completed bars from the same open contract. The time exit uses the first executable quote at or after the configured Riyadh time. If conditions share one event, priority is profit, opposite MACD, then time.

يُقاس الربح من سعر الطلب عند الدخول إلى أول سعر عرض لاحق قابل للتنفيذ. ويعتمد الخروج بالتقاطع العكسي على شموع مكتملة للعقد المفتوح نفسه. أما الخروج الزمني فيستخدم أول تسعير قابل للتنفيذ عند الموعد المحدد بتوقيت الرياض أو بعده. وعند تزامن الشروط تكون الأولوية للربح ثم التقاطع العكسي ثم الوقت.

Research questionسؤال بحثي Which exit actually controls holding time and loss distribution? أي شرط خروج يتحكم فعلياً في مدة الاحتفاظ وتوزيع الخسائر؟

Contracts and commission

عدد العقود والعمولة

Contract count scales gross exposure and dollar P&L; it does not improve the entry signal. Commission is charged per contract and should match the intended validation assumption. The contract multiplier remains fixed at 100.

يؤدي عدد العقود إلى مضاعفة الانكشاف والربح أو الخسارة بالدولار، ولا يحسن جودة إشارة الدخول. وتُحتسب العمولة لكل عقد وينبغي أن تتوافق مع فرضية التحقق المقصودة. ويبقى معامل العقد ثابتاً عند 100.

A complete replay requires all five evidence layers

تتطلب المحاكاة الكاملة خمس طبقات من الأدلة

  1. Session calendarتقويم الجلسات — timezone-aware open and close for each symbol and date. — افتتاح وإغلاق محددان زمنياً لكل رمز وتاريخ.
  2. Underlying pricesأسعار الأصل الأساسي — used at the selection timestamp for ATM/ITM ranking. — تُستخدم عند لحظة الاختيار لترتيب أسعار التنفيذ ATM/ITM.
  3. Contract reference dataالبيانات المرجعية للعقد — OCC identity, call/put, strike, and expiration. — هوية OCC ونوع العقد وسعر التنفيذ وتاريخ الانتهاء.
  4. Five-minute option OHLCVبيانات OHLCV لعقد الخيار — completed trade bars for MACD and optional RSI. — شموع تداول مكتملة لاحتساب MACD وRSI الاختياري.
  5. Timestamped NBBO quotesتسعيرات NBBO المؤرخة زمنياً — bid/ask for eligibility, entry, every exit, and ordering. — أسعار العرض والطلب للأهلية والدخول والخروج والترتيب الزمني.

Behind the button ما يحدث خلف زر التشغيل

Public controls, private execution, offline data إعدادات عامة وتنفيذ خاص وبيانات محلية

The website is a static control surface. The calculation runs only on the trusted Windows runner that holds the allowlisted local files.

الموقع واجهة تحكم ثابتة، ولا تُجرى الحسابات إلا على مشغّل Windows الموثوق الذي يحتفظ بالملفات المحلية المسموح بها.

  1. Browser
    Validate visible inputs التحقق من المدخلات الظاهرة No GitHub or market-data token is placed in the page. لا يوضع في الصفحة أي رمز وصول إلى GitHub أو إلى بيانات السوق.
  2. Gateway
    Authenticate the shared runner key مصادقة مفتاح المشغّل المشترك Cloudflare compares a one-way digest and validates every field again. تقارن Cloudflare بصمة أحادية الاتجاه وتعيد التحقق من كل حقل.
  3. GitHub
    Queue a fixed private workflow إدراج مسار عمل خاص وثابت في قائمة الانتظار The public form cannot choose a command, path, provider, or branch. لا تستطيع الواجهة العامة اختيار أمر أو مسار ملفات أو مزود أو فرع برمجي.
  4. Local PC
    Block provider access and run offline حظر الوصول إلى المزود وتشغيل الاختبار محلياً Provider credentials are removed and project Python network access is blocked. تُزال بيانات اعتماد المزود ويُحظر اتصال Python الخاص بالمشروع بالشبكة.
  5. Verifier
    Re-run and compare the result إعادة التشغيل ومقارنة النتيجة Changed data, settings, timestamps, or receipt fields fail closed. يؤدي تغير البيانات أو الإعدادات أو التوقيتات أو حقول الإيصال إلى رفض النتيجة.
  6. Pages
    Publish only a verified research report نشر تقرير بحثي متحقق منه فقط Publication requires the owner’s separate, scoped repository credential. يتطلب النشر اعتماداً منفصلاً ومحدود الصلاحيات يملكه صاحب المستودع.
