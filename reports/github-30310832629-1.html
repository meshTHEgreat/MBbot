    Loss-threshold evidence

    How far trades moved before exit

    MAE is the worst executable-bid loss observed from entry through exit. It is measured evidence, not a simulated replacement exit. Because observation stops at the trade's actual exit, an enabled stop loss can truncate this path. Research a candidate threshold with an otherwise identical run where that stop is disabled or set looser.

    Threshold reach counts help assess a maximum-loss setting. Winners reached shows profitable trades that would have touched the threshold before their recorded exit; it does not model slippage, later price movement, or counterfactual P&L.
