Exact wide-net entry rule

At 10:25, 11:25, 12:25, 13:25, and 14:25 ET per available symbol-session: positive trailing 15-minute underlying return selects a call; negative selects a put. There is no signal-strength threshold.

Eligible contracts have 1-4 DTE, valid NBBO, bid above zero, ask at or above bid, midpoint at least $0.50, quote age no more than 60 seconds, spread no more than 15%, and nonmissing delta. The contract nearest 0.50 absolute delta wins, then narrower spread, lower DTE, expiration, and strike break ties.

Five minutes later the quote is checked again. One contract is bought at the actual ask.

All seven exit rules

Fixed time: +15, +30, and +60 minutes. Target-stop: +20% / -10% or +40% / -20%, then end of session if untouched. Underlying invalidation: call exits when the underlying reaches or falls below the observation trailing-15-minute low; put exits when it reaches or rises above the high. Session close: 15:55 ET.

Every exit uses the actual normalized one-minute valid-NBBO bid. Missing exact observations remain unavailable. Nothing is interpolated.

Chronological learning split

Train: 146 sessions from 2025-07-25 through 2026-02-23. Internal heldout: 63 sessions from 2026-02-24 through 2026-05-22. Trees, thresholds, leaf sets, and the original headline selection used train only.

The internal heldout is still part of unsealed A2 and has now informed discovery. It is not independent confirmation.

Recommended sequence

Next: try to break it.

Stop tuning. Preserve the sealed blocks. Treat PT40 / SL20 + combined as one research candidate.

Freeze the candidate

Hash the exact entry, exit, feature list, tree thresholds, leaf membership, fill model, and evaluation metrics.

Why: a moving rule cannot receive an honest confirmation test.

Falsify it inside A2

Run monthly walk-forward scoring, leave-one-symbol-out checks, block-bootstrap intervals, multiple-testing correction, predictor ablations, and delayed-fill stress. Do not retune.

Why: these tests can expose concentration and fill fragility without spending sealed data.

Paper trade forward

Collect at least 40 new sessions under the frozen rule before review. Forty is an operating minimum, not a formal power calculation.

Why: fresh time is the only way to escape same-period selection.

Open one seal once

Only after the frozen audit passes, request explicit authorization for a one-time B2 or C2 evaluation. Report the result without adjustment.

Why: sealed evidence has value only before it influences the rule.

Stop condition If any robustness failure triggers a rule change, the changed rule returns to exploratory status. It does not inherit the old heldout result.
